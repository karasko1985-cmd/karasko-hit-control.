# KARASKO HIT CONTROL — uproszczona paczka na GitHub

Wszystkie pliki znajdują się w jednym folderze, bez podfolderów. Zaznacz pliki po rozpakowaniu i prześlij je do głównego katalogu repozytorium GitHub. GitHub musi pokazywać `server.js`, `index.html`, `app.js`, `style.css`, `render.yaml`, `package.json` obok siebie.

W Render wybierz New > Blueprint, podłącz repozytorium `karasko-hit-control.` i dodaj tajne zmienne `OPENAI_API_KEY` i `APP_PASSWORD`. Nie udostępniaj ich na GitHub. API OpenAI jest rozliczane osobno od ChatGPT Plus.

Aplikacja wykorzystuje Node 20+ i standardowe biblioteki Node. Start: `npm start`.
