# Uruchomienie na Render

1. Utwórz prywatne repozytorium GitHub i dodaj do niego pliki z tego folderu (bez .env).
2. Zaloguj się do render.com, wybierz New > Blueprint i połącz repozytorium.
3. Render odczyta render.yaml. Wprowadź prywatnie OPENAI_API_KEY oraz APP_PASSWORD w panelu Render.
4. Zatwierdź wdrożenie. Otwórz przydzielony adres https://...onrender.com.
5. Gdy pojawi się okno logowania, wpisz dowolną nazwę użytkownika i APP_PASSWORD.

API OpenAI jest płatne osobno. Darmowy plan hostingu może usypiać usługę i mieć limity; sprawdź dostępność i cennik w panelu Render. Nie udostępniaj klucza ani hasła w rozmowie lub repozytorium.
